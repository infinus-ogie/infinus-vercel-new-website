# Project instructions

## Copy style

Do not use em dashes (—) in user-facing copy. Use a normal hyphen (-), comma, colon, or
rewrite the sentence.

This applies to anything a visitor reads: page copy in `content/`, metadata titles and
descriptions, and text written directly in components. It does not apply to source code,
code comments, generated assets, third-party text, or URLs.

The frozen legal documents in `content/legal/` are excluded: do not make unrelated
punctuation edits there.
